# CARLA 五场景 A/B 仿真演示

## 仿真软件

本演示使用 **CARLA 0.9.16** 构建自动驾驶仿真环境。CARLA 负责生成道路、车辆、行人、天气、车载相机和碰撞事件；同一场景分别运行固定基线与 YOLO 视觉闭环，形成 A/B 对比。

- **A（固定基线）**：车辆保持固定控制输出，不根据前方目标采取避让动作。
- **B（YOLO 闭环）**：YOLO 检测车辆和行人，触发停车、等待、确认、RESET 和恢复行驶。

## 五个场景

| 场景 | 内容 | B站分 P |
| --- | --- | --- |
| 场景 1：晴天直路静止汽车 | 晴天直路上出现静止汽车，用于验证最基础的车辆检测与停车。 | P1 固定基线；P2 YOLO 闭环 |
| 场景 2：斑马线行人横穿 | 行人在车辆前方横穿道路，用于验证行人检测、提前减速和安全停车。 | P3 固定基线；P4 YOLO 闭环 |
| 场景 3：前车切入并制动 | 前方车辆切入本车道后制动，用于验证动态车辆目标的跟踪与响应。 | P5 固定基线；P6 YOLO 闭环 |
| 场景 4：货车遮挡行人 | 行人被货车部分遮挡后进入危险区域，用于验证遮挡情况下的安全停车。 | P7 固定基线；P8 YOLO 闭环 |
| 场景 5：多车多人复杂路口 | 多辆车和多名行人同时出现，用于验证复杂交通环境中的目标选择与闭环控制。 | P9 固定基线；P10 YOLO 闭环 |
